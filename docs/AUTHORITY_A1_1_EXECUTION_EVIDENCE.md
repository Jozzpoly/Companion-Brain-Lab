## 8. A1.1f — live passive observer contract

### 8.1 Live decision seam

When SPATIAL mode is active and A1 DIRECT/TEMPORAL is selected, the live scene now executes:

```text
current A1Situation @ t
+ the exact current pre-World snapshot
+ the real World static traversal adapter
        |
        v
passive relationship observation
        |
        v
baseline companion decision remains authoritative
        |
        v
A1 resolve returns the exact baseline MotionIntent
```

The observer executes before World submission and uses the same decision-time evidence boundary already qualified by A1.0.

A1 OFF remains silent.

### 8.2 Multi-rate evidence

Cheap semantic/orientation evidence is updated on every A1 decision World tick.

Heavy projection/accessibility evidence is cadence-bounded at:

`6 World ticks`

The runtime exposes separate causal clocks:

- `lastAttemptTick` — an observation attempt occurred;
- `latestTick` — semantic evidence successfully completed;
- `lastHeavyAttemptTick` — heavy evaluation was attempted;
- `heavyAttempts`;
- `heavyEvaluations`.

Cached heavy evidence exposes its own `sourceTick` and `ageTicks`.

No boolean duplicate of freshness is stored as a second truth.

### 8.3 Strict observation epoch

The observer accepts at most one observation attempt per World tick.

Duplicate/backward attempts are contract violations.

A failed attempt still consumes its World tick. A caller cannot repair the input and silently replace failure history inside the same decision tick.

### 8.4 Failure provenance

Failure behavior is causal rather than cosmetic:

- a failed heavy evaluation does not trigger an immediate 60 Hz retry storm;
- heavy retry remains bounded by the World-tick cadence;
- first failure in a World tick wins;
- a later duplicate-call error cannot overwrite the original cause;
- a successful later World tick clears the event evidence;
- failed heavy work does not masquerade as a successful fresh heavy evaluation.

This preserves the same evidence discipline learned during CCC-0.

## 13. Installation / reproducibility caveat

A registry/package-resolution change exposed an npm/Arborist failure unrelated to A1 product behavior:

`Cannot read properties of null (reading 'edgesOut')`

Evidence localized the crash to npm peer-set loading around the Vitest optional browser/devtools peer surface.

Two hypotheses were explicitly tested and rejected:

1. pinning `@vitest/browser-playwright` to `5.0.0` did **not** fix the installer;
2. changing npm `10.9.8 -> 10.9.9` produced the same null dereference.

Neither workaround remains in the dependency graph.

Current CI behavior is deliberately narrow:

1. run normal `npm install` first;
2. if it fails, inspect the npm debug log;
3. allow `npm install --legacy-peer-deps` only when the exact known Arborist `edgesOut` null-dereference is present;
4. any other install failure remains a hard FAIL;
5. the resulting tree must still pass strict TypeScript, all Vitest tests, production build and all browser audits.

This is an infrastructure workaround, not an A1 architecture decision.

Longer-term reproducible dependency installation / lockfile or package-manager policy remains an infrastructure concern to resolve deliberately rather than by accumulating peer overrides.

## 14. Material stage findings

1. **Relationship meaning should be player-relative objective space, not a world target.**
   The useful abstraction survived projection, accessibility and anti-hardcoding tests without requiring one persistent point objective.

2. **Current semantics and heavy World accessibility can live at different cadences.**
   Same-step Owner semantics remain current every World decision tick while expensive route/topology support is explicitly cached with source/age provenance.

3. **Attempt time and successful evidence time are different facts.**
   `lastAttemptTick` and `latestTick` must not be collapsed if failed observations are to remain causally honest.

4. **A failed expensive observation is an event, not permission for an unbounded retry loop.**
   Retry cadence stays tied to World time.

5. **Partial coverage cannot prove global topology.**
   Confirmed accessibility fragments remain evidence subsets until coverage is complete.

6. **A debug representative must not become hidden policy.**
   Representatives remain member-sample adapters only; A1.1 selects no preferred fragment.

7. **Objective meaning and observation mesh are different layers.**
   Direct semantic utility remains valid across materially different sampling meshes and a second synthetic objective profile.

8. **Output non-interference and timing non-interference require separate evidence.**
   Exact command equality was insufficient; the live browser cadence had to be measured independently.

9. **The current A1.1 heavy cadence is viable evidence, not an immutable execution mode.**
   The 6-tick cadence passed this substrate gate but may be redesigned when future controller cost/latency becomes concrete.
