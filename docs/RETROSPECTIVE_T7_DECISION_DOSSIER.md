# 1. Decision in one sentence

Do **not** launch the old OS-PREP-5 as a broad “is this a teammate?” Owner Sandbox.

Prepare a revised Owner experiment whose explicit purpose is:

> **close the movement-foundation era by determining which parts of the current embodied player↔companion locomotion relationship are genuinely worth preserving into the first real minimum-useful-partner stage.**

---

# 2. True current project state

The current live companion is not merely a chase follower.

It has earned substantial embodied competence:

- physical World truth;
- whole-body traversal;
- responsive omnidirectional local motion;
- player-motion-aware collision risk;
- hard-vs-comfort space;
- temporal body continuity;
- bounded local recovery;
- autonomous reacquisition;
- strong causal/debug provenance.

But it is not yet the broader local live brain described by the project north star.

Its highest-level ordinary purpose is still:

> maintain/recover a player-relative movement relation.

It has no current world/action vocabulary for:

- threat;
- assistance;
- readiness;
- engagement/disengagement;
- tactical responsibility;
- command meaning;
- role;
- explicit meaningful initiative.

Therefore the present organism cannot fairly answer:

> “does this feel like the teammate I imagined?”

It can answer:

> “is this embodied movement relationship a strong enough substrate for that teammate?”

---

# 3. Why the movement campaign was still worth doing

The retrospective rejects a simplistic “we wasted a week on movement” interpretation.

S1, S4 and R1 Owner failures showed that weak body/movement competence would contaminate every later cognition experiment.

The campaign earned difficult primitives that a future brain should not have to reinvent.

The problem was not going deep.

The problem was allowing the depth of the movement research apparatus to blur the distinction between:

- **foundation competence**;
- **teammate cognition**.

That distinction is now restored.

# 11. Why not add threats before this Owner run?

The retrospective considered the alternative:

> add one small shared responsibility first so the Owner evaluates a more teammate-like stimulus.

That would make the experiment broader, but it would also compound two unknowns:

1. whether the current body/relationship foundation actually feels worth keeping;
2. whether the first new responsibility/brain mechanism is good.

Because movement has consumed so much project attention, the highest-information next human question is now:

> **can we consciously close or sharply demote movement as the main research problem?**

A narrow Owner run can answer that cheaply.

If the answer is “no, movement still undermines everything”, fix the most salient cause before Stage B.

If the answer is “yes, good enough / promising”, stop deepening the movement lab and move into actual shared responsibility.

This prevents another large pre-Owner architecture campaign.
